# ◆ Parfum — Catálogo de Perfumes

Catálogo online de perfumes com carrinho de compras e cadastro de clientes.

## Como publicar na Vercel

1. Crie um repositório no GitHub (ex: `parfum-catalogo`)
2. Suba os arquivos deste projeto para o repositório
3. Na Vercel, clique em **"Add New Project"**
4. Selecione o repositório `parfum-catalogo`
5. Clique em **Deploy**
6. Pronto! Seu site estará no ar em `seu-nome.vercel.app`

## Personalizações

- **Perfumes**: Edite o array `perfumes` no `index.html` para adicionar/remover/alterar produtos
- **WhatsApp**: Troque o número no link do botão flutuante (procure por `wa.me/`)
- **Nome da loja**: Altere "Parfum" nos locais indicados
- **Cores**: Modifique as variáveis CSS no `:root`
